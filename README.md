## 📱 How to Use

1. **Install APK**: Download and install `OCR-MCQ-Solver.apk`.
2. **Log into Google Gemini**: Open the app and tap **"🔑 Log into Google / Gemini"** to authenticate once.
3. **Grant Permissions**:
   - Draw over other apps (`SYSTEM_ALERT_WINDOW`)
   - Screen capture / MediaProjection
4. **Choose Display Mode**: Keep **"🥷 Stealth Option-Only Mode"** selected.
5. **Start Solving**:
   - Switch to Chrome or your quiz/exam app.
   - **Single-Tap** the virus bubble -> Solves and displays the correct option (**A/B/C/D**).
   - **Double-Tap** the virus bubble -> Toggles 95% invisible Ghost Mode!
