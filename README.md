## 🛠️ Hard-Won Engineering Challenges & Real-World Fixes

### 1. The Chrome Hover Tooltip Exposure Trap
- **The Issue:** Even with an innocent extension name and icon, hovering mouse cursor over the toolbar button showed `"Smart Vision (Click to solve MCQ)"` because `action.default_title` in `manifest.json` hardcoded that title.
- **The Solution:** Sanitized `manifest.json` to `"default_title": "Google Translate"` and built `getStealthTooltip(config)` in `background.js` to dynamically set innocent hover strings matching the user's active camouflage disguise.

### 2. Proctor Detection via Letter Badges
- **The Issue:** Traditional browser solvers show `A`, `B`, `C`, `D` badges on the toolbar icon. Screen recordings or webcam proctors easily recognize this pattern as an answer key.
- **The Solution:** Engineered the **Coded Symbol Icons Engine**, replacing letter badges with innocent symbols (Airplane, Balloon, Cloud, Diamond, Anchor, Book, Clock, Document). To an observer, the icon appears as an ordinary productivity utility.

### 3. Gemini Free API Quota Depletion
- **The Issue:** Cloud API keys frequently hit HTTP 429 quota exhaustion during lengthy exams.
- **The Solution:** Developed the **Headless Gemini Web Engine** (`companion/headless_gemini_server.py`) using Playwright to automate an authenticated Google Gemini web chat session. Uncapped reasoning, infinite questions, zero token billing.

### 4. Pocket Vibration Throttling in Mobile Browsers
- **The Issue:** Mobile browsers throttle the Web Vibration API when the screen locks or tabs enter background power saving.
- **The Solution:** Added a deep-link custom scheme (`omnisolve://sync`) allowing the QR code to launch the **OmniSolve Native Android App**, leveraging a persistent foreground service and native Android `Vibrator` hardware access.

## ❓ FAQ & Troubleshooting

#### Q1: What should I do if the toolbar icon tooltip still shows "Smart Vision"?
**A**: Ensure you are using v1.9. Open `chrome://extensions/`, click the refresh button on the Smart Vision extension card. Then open Options $\rightarrow$ Stealth tab, click `🔄 Auto-Match`, and click **Save Stealth Preferences**. The tooltip will immediately update to your innocent camouflage text.

#### Q2: Can proctoring software detect the keyboard Caps Lock blinking?
**A**: No. The companion server uses low-level Win32 hardware keyboard status updates (`SetKeyboardState` / `keybd_event`) that do not inject keystroke events into the browser DOM or trigger JavaScript `onkeydown` listeners.

#### Q3: How do I test Coded Symbols without waiting for a real question?
**A**: Open Extension Options $\rightarrow$ **Tab 2: Stealth & Camouflage** $\rightarrow$ Under "Coded Symbol Mappings", click **Test A**, **Test B**, **Test C**, or **Test D**. The active browser tab's extension icon will immediately morph into your selected symbol!

#### Q4: What if I lose internet access or Google Gemini is blocked?
**A**: You can add your personal Gemini API key in Tab 1 of Options, or run the Android native app with on-device Google ML Kit OCR.
